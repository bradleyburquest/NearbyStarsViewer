# NearbyStarsViewer  
  
I want you to create a NearbyStarsViewer application. The application will have the following requirements and features.   
  
1. Run in Chrome, Safari, DuckDuckGo, Firefox.  
2. Create a 3-d application that allows the user to view the 150 closest stars to our sun.  
3. The viewer will have the ability to:  
    1. view from earth and view from the sun (earth centered and sun centered) but selectable.  
    2. show the nearby stars with RA, DEC location data, star classification, size, distance, planet data, magnitude, apparent and proper motion (with direction arrow), and other relevant data.  
    3. the UI can zoom in an out, rotate the view.   
    4. show the major constellations and galactic plane in the background to orient the viewer with the location and allow the user to turn this feature on an off or change the visibility intensity.  
    5. the viewer can be maximized in the browser.   
    6. have the ability to zoom in/out the viewing distance which will show/unshow the stars within that distance.  
    7. show/unshow the equatorial grid, ecliptic, and galactic grid, each can be selected individually.
